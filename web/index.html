Schedule

Rules are checked top to bottom and the first one that matches now decides the screen. Put the rarest on top and a rule with no time last as the fallback.

A screen is pinned, so the schedule is paused.

Time format

Cron, in the Pi's local time: min hour day month weekday, or six fields with leading seconds. Weekday 0 is Sunday. Each field takes *, numbers, ranges (9-16), lists (1,3) and steps (*/15).

0 */15 * * * * the start of every quarter hour · 0 0 * * * * every hour · * 9-16 * * 1-5 every second of weekday 9am to 4:59pm

"For" is how many seconds the screen stays up from each firing (default 60).

Rotation

Cycles through these screens when no schedule rule matches.

A screen is pinned, so the rotation is paused.

Sleep

The matrix goes dark from start until end (it may cross midnight). Sleep wins over everything else.

Data sources

Change what a screen shows, such as a market symbol. Only values that differ from the screen's own are saved.
